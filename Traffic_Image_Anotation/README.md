# Traffic Image Annotation Project

## 1.0 Project Overview

This project involves annotating traffic related images to identify and classify objects commonly found in road environments. The project was created as a practical exercise in AI data annotation and computer vision.

## 2.0 Project Objectives

Identify and label objects in traffic images
Practise accurate object annotation using bounding boxes and polygons
Understand how annotated datasheets support AI and machine learning models.
Develop practical data annotation skills

##  3.0 Datasheet Description
The datasheet consists of five images covering different road and traffic scenarios:
- Traffic scenes
- Persons\pedestrians
- Motorcycles
- Parking

## 4.0 Annotation Techniques
Two annotation techniques were used:
- Polygon Box Annotation: Polygons were used to trace the outlines and shapes of selected objects.
- Bounding Box Annotation:Rectangular boxes were drawn around identified objects.
